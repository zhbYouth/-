# 吐纳

呼吸练习应用（tǔ nà）。同一份代码可以当网页用、装到手机主屏幕，也可以打包成 Android 安装包。

视觉上取「宣纸与墨」：纸面带纹理，呼吸画成会晕开的墨，一炷香计时，练完盖一枚印章。每种方式配一种传统颜料色（朱砂、石青、藕荷、石绿、赭石），自动跟随系统深浅色。

## 安装

**Android 安装包（APK）**
仓库的 [Releases](../../releases/tag/latest) 页面里下载 `tuna.apk`，在手机上打开安装。首次安装需要允许「安装未知来源应用」。这是调试签名的测试版，适合自己使用，不能直接上架应用商店。更新前请先卸载旧版。

**网页版 / 添加到主屏幕**
开启 GitHub Pages 后访问 `https://zhbyouth.github.io/-/`，用手机浏览器选择「添加到主屏幕」，离线也能打开。

## 怎么用

- **按住圆相**约一秒开始练习，圆相上的圆环会随按压填满。
- **左右轻划**圆相，换一式；点右上角或右侧题款进入目录，查看做法、依据和设置。
- 时长在底部的「尺子」上选：一、三、五、十分钟。
- 练习中左侧的香会随时间燃短，结束时盖章。
- 返回键逐层返回：练习中 → 完成页 → 主界面；目录 → 主界面。只有在主界面才会退到后台。

## 呼吸方式与依据

只保留有同行评审研究或官方指导支持的方式，并在应用里写明依据和局限。

| 方式 | 节奏 | 依据 |
| --- | --- | --- |
| 循环叹息 | 鼻吸 3 秒 + 再吸 1 秒，呼出 6 秒 | Yilmaz Balban 等，*Cell Reports Medicine*，2023：108 人、28 天、每天 5 分钟的随机对照试验，对积极情绪和呼吸频率的改善最明显。样本小，随访 4 周。具体秒数是本应用的设定。 |
| 共振呼吸 | 吸 5 秒，呼 5 秒，每分钟 6 次 | Zaccaro 等，*Frontiers in Human Neuroscience*，2018：15 项研究的系统综述，每分钟 10 次以下的慢呼吸与心率变异性上升、放松感增加相关。没有随机对照试验。 |
| 四六呼吸 | 吸 4 秒，呼 6 秒 | 同属每分钟 6 次的慢呼吸。呼气更长是否有额外作用，证据有限。 |
| 缩唇呼吸 | 鼻吸 2 拍，噘嘴呼 4 拍 | 美国国立医学图书馆 MedlinePlus 患者指导，用于活动时气短或焦虑。 |
| 自定节奏 | 吸、屏、呼、停各自设定 | 显示每分钟次数，超过 10 次时提示不属于研究里的慢呼吸。 |

已移除：4-7-8、唤醒呼吸、箱式呼吸。它们要么缺少可靠的人体研究，要么在对照试验里没有显著优于正念。

## 语音引导

练习时用手机自带的中文语音引擎，以偏慢、偏高的音调温柔地引导，可以在目录的「器物」里挑选声音并试听。不同手机的语音引擎不同，音色以实际为准；如果没有中文语音，请在系统设置里安装中文语音引擎。

## 字体与素材

- 正文：霞鹜文楷（LXGW WenKai，SIL OFL 1.1），按页面用到的字裁剪为 `fonts/wenkai.woff2`
- 题字：马善政（Ma Shan Zheng，SIL OFL 1.1），裁剪为 `fonts/brush.woff2`
- 纸张纹理 `textures/` 为程序生成

## 自己构建

```bash
npm install
npm run build:web      # 把网页文件整理到 www/
npx cap sync android   # 同步到 Android 项目
cd android && ./gradlew assembleDebug
# APK 输出：android/app/build/outputs/apk/debug/app-debug.apk
```

构建 APK 需要 Node 18+、JDK 17 和 Android SDK。推送到 `main` 后，GitHub Actions 会自动构建并更新 Releases 里的安装包。

## 目录

| 路径 | 说明 |
| --- | --- |
| `index.html` | 整个应用（页面、样式、脚本） |
| `fonts/`、`textures/` | 裁剪后的字体、纸张纹理 |
| `manifest.webmanifest`、`sw.js`、`icons/` | 添加到主屏幕和离线使用 |
| `android/`、`capacitor.config.json` | Android 项目（Capacitor），含沉浸式状态栏、返回键接管和语音接口 |
| `.github/workflows/` | 自动打包 APK、发布网页版 |

## 提示

这是放松练习，不能替代诊疗。练习中出现头晕、手脚发麻时，请恢复自然呼吸并停止。孕期或有心肺疾病时，练习前先咨询医生。
